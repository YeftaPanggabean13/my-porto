## 💻 Getting Started

### Prerequisites

* Node.js (v18.x or later)
* npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YeftaPanggabean13/react-portfolio.git
   cd react-portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Build for production:
   ```bash
   npm run build
   ```

5. Preview the production build locally:
   ```bash
   npm run preview
   ```
